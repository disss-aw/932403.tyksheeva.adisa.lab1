\##  Что реализовано



\### Семантическая структура HTML5

\- `<header>` — шапка с именем, описанием и аватаром

\- `<main>` — основной контент страницы

\- `<section>` — смысловые разделы (Навыки, Проекты, Контакты)

\- `<aside>` — боковая панель с информацией о любимом созвездии

\- `<footer>` — подвал с копирайтом



\### Контент

\- \*\*Навыки\*\* — маркированный список (`<ul>`) научных и технических навыков, связанных с космосом

\- \*\*Проекты\*\* — нумерованный список (`<ol>`) из 4 космических миссий и объектов

\- \*\*Форма обратной связи\*\* — поля "Имя", "Email", "Сообщение" с кнопкой отправки

\- \*\*Изображение\*\* — аватар с атрибутами `src`, `alt`, `width`, `height`



\### Дизайн и стилизация (CSS)

\- \*\*Космический фон\*\* — звёздное небо, созданное с помощью CSS-градиентов (`radial-gradient`) без использования изображений

\- \*\*Золотой градиентный текст\*\* — заголовки оформлены эффектом металлического золота (`linear-gradient` + `background-clip: text`)

\- \*\*Цветовая гамма\*\* — тёмно-синяя с золотистыми акцентами (космическая эстетика)

\- \*\*Эффекты\*\* — скруглённые углы, полупрозрачные блоки, hover-эффект на кнопке



\## Технологии

\- HTML5 (семантическая вёрстка)

\- CSS3 (градиенты, стилизация форм, адаптивность)
